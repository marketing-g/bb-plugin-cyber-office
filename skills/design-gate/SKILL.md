# Creative review

Record a reference and measurable acceptance criteria in the brief before starting. If either is missing, check project material first, then ask the coordinator or user for the missing decision.

Make one sample. Have the critic compare it with the reference and criteria, then show it to the user. Wait for an explicit yes before producing the series. Preserve the approved recipe across the series and review any proposed change before applying it.
