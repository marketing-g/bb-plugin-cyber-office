# Changelog

## 0.1.0

First public release.

- Pixel office with a coordinator, specialists, and a critic that cannot be switched off
- Twelve built-in roles, six on by default, plus your own agents
- Cyborg card: name, look, glow color, provider, model, effort, skills, tool labels
- Skill picker by category with recommendations for the role
- Question cards with options and a default, result cards on every reply
- `team-setup` skill that proposes a team for your project
- Demo run on a made-up coffee shop task with a spend cap
- English and Russian interface
- Experimental: foreman, scout, shift handoff for long coordinator threads
- Safety: boards stay inside their project, caps on new threads and shift handoffs, files open only for documents and images, text between threads is quoted as data
